## 다음: Phase 2 — 핵심 프로토타입

통과 기준: 10웨이브를 터치로 끝까지 플레이 가능, 헤드리스 시뮬레이션이 돈다.

1. `data/` JSON과 스키마 검사(파일·줄 번호 오류). 처음에는 SENTINEL·CRYO·R-07·R-11·H-02와 1장 1~10웨이브만.
2. `src/sim/`: 고정 60틱, 시드 RNG, 경로(Neon District 중심선), 웨이브, 적 이동, 배치 가능 판정, 표적 선택, 발사체, 피해 유형 계수, 크레딧·에너지, 코어, 승패. DOM·Pixi 의존 없음.
3. `tools/`: 헤드리스 러너(`npm run sim`), 결정론 테스트(같은 입력 → 같은 해시).
4. 단순 도형 렌더러(Pixi) + 터치 입력: 레일에서 드래그 배치, 탭 배치 모드, 핀치 줌·이동, 선택·판매 확인. 제스처 우선순위는 03장 표.
5. Playwright로 터치 흉내 테스트, 1180×820·1366×1024·1024×768 스크린샷.
