# NEXUS: FRONTLINE 설계 문서

Phase 1 산출물. 지시서 v2.1의 00·03~12장을 이 게임의 수치와 규칙으로 구체화했다.
수치는 시작점이다. Phase 3에서 헤드리스 밸런스 시뮬레이션(지시서 19장) 결과로 고치고, 고친 이유는 `docs/decisions.md`에 남긴다.

표기:
- 거리는 칸(1칸 = 48pt), 시간은 초(s), 속도는 칸/s. 시뮬레이션은 초당 60틱 고정이다.
- 크레딧은 CR, 에너지는 EN으로 줄여 쓴다.
- **반드시** 항목은 어기면 실패, 그 밖의 수치는 권장값이다.

## 2. 전투 기본 규칙

### 2-1. 피해 유형과 적 특성 계수 (반드시)

모든 공격은 운동·에너지·전기·폭발 중 하나다. 계수는 곱으로 적용한다.

| 적 특성 | 운동 | 에너지 | 전기 | 폭발 | 비고 |
| --- | --- | --- | --- | --- | --- |
| 일반 | 1.0 | 1.0 | 1.0 | 1.0 | |
| 중장갑 | 0.4 | 1.0 | 1.0 | 1.1 | 운동 계수 = 1 − 0.6 × (1 − 장갑 관통) |
| 보호막(보호막에 맞을 때) | 1.0 | 0.25 | 2.0 | 1.0 | 넘친 피해는 본체 계수로 넘어간다 |
| 보스 장갑판: 운동형 | 0.5 | 1.0 | 1.0 | 1.0 | 20초마다 전환 |
| 보스 장갑판: 에너지형 | 1.0 | 0.5 | 1.0 | 1.0 | |
| 적응형(3장) | 맞은 유형 최대 0.6 | | | | 10초 안 맞으면 초당 0.05씩 회복 |

- 보호막은 3초 동안 피해를 받지 않으면 초당 최대 보호막의 8%씩 재생한다.
- 은폐형은 **표적으로 지정할 수 없을 뿐** 범위 피해(폭발 반경, CRYO 펄스, 지휘 기체 포격)에는 맞는다. 연쇄 전기는 표적 지정이므로 탐지가 필요하다.
- 비행형은 대공 가능 유닛만 맞힌다(2장부터 등장).

### 2-2. 높이 규칙: 고가 구간 (Neon District)

경로 일부가 고가도로 위로 지난다. 지상 유닛은 방음벽에 사격선이 막힌다.
고가 구간의 적은 **높이** 속성이 있는 유닛만 표적·효과 대상으로 삼는다.

| 높이 있음 | 높이 없음 |
| --- | --- |
| RAIL-X, ARC, KESTREL, SENTINEL(B1 이후) | SENTINEL(기본), CRYO(펄스는 지면 효과) |
| RAIL-X C3 범위 안 아군 | OVERCLOCK·REACTOR(공격 없음, REACTOR B 방전 포함) |

### 2-3. 표적 우선순위

선두 / 마지막 / 강한 적 / 가까운 적 / 지원형 먼저 / 비행형 먼저.
그 장에 나오는 적 구성에 해당 유형이 없으면 그 항목은 선택지에 나오지 않는다. 1장은 앞의 4개만 보인다(`decisions.md` D-07).

- 선두: 코어까지 남은 거리가 가장 짧은 적
- 마지막: 남은 거리가 가장 긴 적
- 강한 적: 현재 체력(보호막 포함)이 가장 높은 적, 같으면 선두
- 가까운 적: 유닛에서 가장 가까운 적

### 2-4. 업그레이드 규칙 (반드시)

- 경로 A(화력), B(제어·특수), C(유틸리티·시너지), 경로당 6단계.
- 한 유닛에서 업그레이드할 수 있는 경로는 2개까지. 그중 하나만 3단계 이상(주력 경로), 다른 하나는 최대 2단계.
- **Tier = 주력 경로의 단계.** 두 경로 모두 2단계 이하이면 Tier = 더 높은 쪽(0~2).
- 같은 유닛·같은 경로의 Tier 6은 맵에 하나만.
- Tier 6은 캠페인 3장 클리어 후 해금. 그 전에는 "설계 데이터 없음 — 3장 생산 라인 이후"로 표시한다.
- 각 단계는 수치 외에 공격 방식·표적 규칙·새 능력·상호작용·자원 규칙 중 하나를 바꾼다. 수치만 오르는 단계는 경로당 최대 2개.
- 가격: 단계 1~6 = 기본가 × 0.6 / 1.0 / 2.0 / 4.5 / 12 / 35 (10 CR 단위 반올림 없음, 표의 값이 정본).

진화 단계 이름: Tier 0 Prototype, 1 Enhanced, 2 Advanced, 3 MK-II Evolution, 4 Specialized, 5 Apex Evolution, 6 Singularity.

### 2-5. 강화 중첩 (반드시)

- 강화 종류: 공격 속도, 사거리, 피해, 발사체, 탐지, 에너지 생산, 둔화(적에게).
- 같은 종류는 크기 순으로 최대 3개 적용: 1번째 100%, 2번째 60%, 3번째 30%. 4번째부터 무시.
- 공격 속도 강화 합계 상한 +80%(REACTOR 고출력 모드 포함). 예외는 VEGA "공명" 하나.
- 계산 순서: 기본 수치 → 자기 업그레이드 → 외부 강화(중첩 규칙) → 상한.
- 유닛 선택 시 하단 패널에 받고 있는 강화와 실제 적용량을 표시한다. 예: `공격 속도 +15% (OVC-02) · +9% (OVC-05, 2번째 60%)`.

### 2-6. 시너지 (이번 작업 구현 2개)

| 조합 | 효과 | 조건 |
| --- | --- | --- |
| CRYO + ARC | 둔화된 적에게 ARC 연쇄 횟수 +2 | 둔화 상태는 CRYO가 건 것만 |
| REACTOR + 공격 유닛 | 에너지 25로 10초 고출력 모드: 공격 속도 +40%, 피해 +20%. 대상별 재사용 15초 | 공격 유닛이 REACTOR 공급 반경(3칸) 안 |

고출력 모드는 공격 유닛을 선택했을 때 하단 패널 오른쪽 "특수 능력"에 버튼으로 나온다. 공급 가능한 REACTOR가 없으면 버튼 자체를 숨긴다.

설계만 하는 10개: LINK + SWARM, EMP + PHANTOM, OVERCLOCK + PRISM, GRAVITY + TITAN, TETHER + SAPPER, OBSERVER + RAIL-X, BULWARK + LANCE, SCRAMBLER + PRISM, STASIS + HALO, RELAY + LINK (지시서 06장 수치 그대로).

## 10. 데이터 구조

모든 데이터는 `data/` JSON이다. 읽을 때 스키마로 검사하고, 오류는 `data/units/sentinel.json:42 paths.A[3].cost: 숫자가 아님`처럼 파일과 줄로 알린다.

```
data/
  units/<id>.json        유닛 1종 = 파일 1개 + 그리기 함수 1개 (src/render/units/<id>.ts)
  commanders/<id>.json
  enemies.json
  bosses/<id>.json
  maps/<id>.json         격자, 경로, 고가 구간, 노드, 건물, 소품
  waves/<map>_<difficulty>.json
  difficulty.json
  story/c<n>.json        id, chapter, trigger, speaker, channel, text, unlock
```

업그레이드 효과 연산(정해진 조합만 쓴다):

| op | 예 |
| --- | --- |
| `mul` / `add` | `{ "op": "mul", "stat": "fireInterval", "value": 0.8333 }` |
| `set` | `{ "op": "set", "stat": "elevated", "value": true }` |
| `projectile` | `{ "op": "projectile", "value": "twin" }` |
| `targeting` | `{ "op": "targeting", "rule": "detectStealth" }` |
| `behavior` | `{ "op": "behavior", "id": "focusFire", "params": { "step": 0.1, "max": 5 } }` |
| `aura` | `{ "op": "aura", "buff": "range", "value": 0.1, "radius": 2 }` |
| `ability` | `{ "op": "ability", "id": "saturation", "cooldown": 60, "energy": 0, "params": { "duration": 8 } }` |
| `economy` | `{ "op": "economy", "id": "waveCredits", "value": 50 }` |

확장 지점(이번 작업은 필드만): `transcend`(초월 진화 조건과 대가), `research`(연구 노드), `mastery`(유닛 숙련), `modes`(부가 모드 규칙), 유닛 데이터의 `unlockChapter`.
