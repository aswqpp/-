# 다리를 가장 싸게 만드는 법 — 설명 영상

「강 트러스교의 비용 최소화 설계」 탐구 보고서를 고등학교 2학년 눈높이로 풀어 설명하는 Remotion 영상입니다.
1920×1080, 30fps, 약 14분 40초. 음성 없이 화면 아래 자막(내레이션)으로 따라갈 수 있게 만들었습니다.

## 구성

| 부 | 내용 |
|---|---|
| 1부 무대 | 동아리 과제, 비용 네 가지, 43번의 수정, 첫 번째 의문의 답(제품비) |
| 2부 개념 7가지 | 트러스 · 눌림과 당김 · 좌굴 · 세장비 · 정정구조 · Pratt/Howe/Warren · 포물선 |
| 3부 계산 프로그램 | 다리 하나를 평가하는 6단계, 44,544개 설계 |
| 4부 반전 | 26.6% → 1·2·3차 시험 → 규칙 확정 → 9.7% |
| 5부 결과 | 2.6배 · 규격 6종 · 모양과 사재 동시 결정 · 포물선 경계 · 세 다리 비교 |
| 6부 생각해 볼 점 | 양방향 통행 · 43번 반복의 도달 수준 · 가장 싼 다리 = 가장 약한 다리 · 배운 것 |
| 정리 | 한 문장 요약, 숫자 요약, 정확하게 말해야 할 점 |

## 파일

- `src/scenes/Part1.tsx` ~ `Part6.tsx`: 장면과 자막 문장(`*_LINES`)
- `src/registry.tsx`: 장면 순서
- `src/lib/timing.ts`: 자막 글자 수로 장면 길이를 정하는 규칙
- `src/lib/truss.ts`: 트러스 모양과 힘의 평형 계산(부재가 눌리는지 당겨지는지)
- `src/lib/theme.ts`: 색 (눌림 = 주황, 당김 = 파랑, 가장 좋은 설계 = 초록)
- `public/fonts`: Pretendard 글꼴 (SIL OFL)

자막 문장을 고치면 장면 길이도 자동으로 다시 계산됩니다.

## 명령

```bash
npm i
npm run dev            # Remotion Studio에서 미리 보기
npx remotion render BridgeExplainer out/bridge-explainer.mp4
```
