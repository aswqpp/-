# VocaLoop — 영단어 학습 앱

플래시카드 기반 학습과 간격 반복(Spaced Repetition) 복습을 중심으로, 애너그램·단어 조합 게임으로 재미있게 복습할 수 있는 영단어 암기 앱입니다.

## 주요 기능

- **단어장 관리**: 카테고리/시험 종류/난이도별 단어 CRUD, 발음 듣기(TTS)
- **플래시카드 학습**: 앞/뒤 뒤집기, 안다/모른다 체크, 진행률 표시
- **간격 반복 복습(SM-2 알고리즘)**: 정답/오답에 따라 복습 주기를 자동 조정, 오늘 복습할 단어 자동 추천
- **퀴즈 모드**: 객관식(뜻 고르기), 스펠링 입력, 듣고 뜻 맞추기
- **게임**: 애너그램 게임, 단어 조합 게임 — 게임 결과가 복습 우선순위에 반영됨
- **학습 통계**: 연속 학습일(스트릭), 오늘 학습량, 정답률, 최근 7일 추이, 단어 숙련도
- 모바일 우선 반응형 UI, 다크모드 지원

## 기술 스택

- React 19 + TypeScript + Vite
- Tailwind CSS v4
- 데이터 저장: `localStorage` (브라우저 로컬 저장, 서버 없이 동작)
- 발음: Web Speech API (`speechSynthesis`)

## 개발

```bash
npm install
npm run dev      # 개발 서버 실행
npm run build    # 프로덕션 빌드
npm run lint     # oxlint 검사
```
