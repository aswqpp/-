# beOm — 영단어 학습 앱

플래시카드 기반 학습과 간격 반복(Spaced Repetition) 복습을 중심으로, 애너그램·단어 조합·카드 짝맞추기 게임으로 재미있게 복습할 수 있는 영단어 암기 앱입니다.

## 주요 기능

- **폴더형 단어장 관리**: 카테고리별 폴더 목록 → 폴더 진입 시 그 안의 단어 목록. 검색은 전체 단어장을 가로질러 조회
- **단어 추가 시 사전/번역 자동완성**: 단어 입력 후 조회하면 발음기호·품사별 발음(동음이의어 포함)을 가져오고, 영어 정의를 한국어로 번역해 뜻 후보로 제시. 뜻만 입력해도 영단어 후보를 역으로 추천. 품사가 여러 개인 단어는 품사별로 별도 카드로 분리 저장 가능
- **대량 단어 등록**: `.xlsx`/`.csv`/`.docx` 업로드, 헤더 자동 매칭 + 수동 열 매칭 화면, 가져오기 결과 요약
- **난이도 자동 측정 (반감기 모형)**: 몇 번 틀렸는지가 아니라 **얼마나 빨리 잊는지**로 잽니다. 복습 간격과 정답 여부에서 단어별 반감기를 추정하고(연습 효과·모드별 난이도·객관식 찍기 확률은 단어장 전체에서 함께 추정해 제거), 단어장 평균보다 확실히 빠르거나 느릴 때만 어려움/쉬움을 **확정**해요. 확신이 부족한 단어는 보정 오답률로 **잠정 표시**하고(칩을 누르면 확정/잠정 여부가 설명으로 뜹니다), 한 번도 안 푼 단어는 `-`(미평가)
- **플래시카드 학습**: 앞/뒤 뒤집기, 안다/모른다 체크, 진행률 표시, 뒷면에 예문·동의어/반의어·메모 표시
- **발음 자동 재생**: 문제로 단어가 나오면 바로 읽어줘요. 정답이 단어 자체인 문제(스펠링·뜻→단어)에서는 재생하지 않고, 예문 읽기는 따로 켤 수 있어요 (설정에서 on/off, 기본 ON)
- **예상 기억률 + 망각 위험군**: 추정한 반감기로 단어별 현재 기억률을 계산해 카드에 표시하고, 기준 아래로 떨어진 단어는 홈에서 바로 복습할 수 있게 모아줘요. 기준은 설정 → 학습 설정에서 민감(90%)·보통(80%)·느슨(70%)·사용 안 함 중에 고를 수 있어요. 반감기를 아직 못 잰 단어는 SM-2 간격에서 유도한 곡선으로 대체합니다
- **오래 안 본 단어 우선 노출**: 학습·퀴즈·게임 모두 마지막 복습 이후 지난 시간에 비례해 출제 확률이 올라가요
- **세션 범위 좁히기**: 학습·퀴즈·게임 모두 카테고리 / 즐겨찾기 / 난이도(미평가 포함)로 대상을 좁혀서 시작
- **간격 반복 복습(SM-2 알고리즘 v4)**: 정답 q=5(+0.10) / 오답 q=2(−0.32)로 EF가 오르내리고(1.3~3.0), 복습 간격은 1일 → 6일 → 이전 간격×EF로 늘어나요. 응답 시간은 **기록만 하고 채점에는 쓰지 않습니다** — 실측 평균 9.70초에 15초 기준을 걸면 보통 속도의 정답이 q=4(변화량 0)가 되어 "EF가 회복되지 않는" 원래 버그가 되살아나기 때문이에요. 데이터가 쌓이면 백분위로 다시 설계할 예정이라 모드별 제한 시간 표는 그대로 남겨뒀고, `TIME_GRADING_ENABLED`만 켜면 동작합니다
- **퀴즈 모드**: 객관식 암기 모드(단어→뜻/뜻→단어 양방향, 선택지 3~5개), 스펠링 입력, 듣고 뜻 맞추기. 문제 수는 5/10/20/전체 또는 직접 입력. **오답 선택지는 정답과 헷갈릴 만큼 뜻이 비슷한 단어**로 고릅니다(뜻의 글자 유사도 + 같은 품사·카테고리 + 사전이 알려준 동의어)
- **게임**: 애너그램, 단어 조합, 카드 짝맞추기(시간·시도 횟수 기록) — 게임 결과가 복습 우선순위에 반영됨. 카테고리·난이도로 범위 좁히기 가능
- **홈 화면**: 오늘 목표 진행률 링, 학습/퀴즈/취약 단어 바로가기, 망각 위험군 알림, 취약 단어 Top 5(개별·전체 집중 복습 연결)
- **학습 통계 대시보드**: 연속 학습일·오늘 학습량·전체 정답률, 누적 기록(최장 연속·학습한 날·누적 단어/풀이·일평균·최고 기록·총 학습 시간), 날짜별 학습량 라인 차트(30/90일), 누적 학습 곡선(누적 단어 수 vs 그날의 오답률), 요일별 학습 패턴, 암기 단계 5단계(미학습·학습 중·복습 중·암기 완료·망각 위험군), 기억 유지력(평균 오답률·평균 응답 시간·복습 붕괴 횟수), 정답률 추이(7/30일), 카테고리별 숙련도 요약, 난이도별 분포, 복습 예정, 펼쳐보는 난이도 계산식 안내
- **카테고리별 숙련도 전용 화면**: 카테고리가 많아져도 통계가 복잡해지지 않도록 분리 — 전체 숙련도, 정렬(단어 수/숙련도/이름), 카테고리별 암기 단계 분포
- **단어 목록 다중 선택**: 체크박스로 여러 개 골라 한 번에 삭제. PC에서는 카드를 누른 채 드래그해서 범위 선택
- **시도 이력 기록**: 채점 하나하나를 단어별 이력으로 남겨요(모드·방향·품질 점수·응답 시간). 학습 기록은 이 이력에서 **파생**되므로 따로 집계하다 빠뜨리는 일이 구조적으로 없어지고, 예전 버전에서 쓰던 기록은 업그레이드 시점을 경계로 그대로 보존돼요
- **모드별·방향별 정확도**: 어떤 방식으로 물었을 때 잘 맞히는지 비교해요. 업그레이드 이전 기록은 모드·방향 정보가 없어 이 집계에서는 빠지고(전체 정답률에는 포함), 화면에 "이전 기록 N회 포함" 각주로 표시돼요
- **데이터 초기화**: 설정에서 모든 단어·기록을 한 번에 삭제 (2단계 확인)
- **나만의 암기 팁(메모)**: 단어마다 니모닉을 적어두면 플래시카드 뒷면·퀴즈 정답 화면·목록에 함께 표시
- **동의어/반의어**: 사전 조회 시 응답에 포함돼 있으면 자동으로 저장하고 카드에 표시 (제공되지 않는 단어도 많음)
- **하루 목표 + 진행률**: 목표 단어 수를 설정하면 홈 화면에 오늘 달성률이 링으로 표시
- **데이터 백업/복원**: 전체 데이터를 JSON 파일로 내보내고, 합치기 또는 덮어쓰기로 복원
- **설치형 앱(PWA)**: 홈 화면에 설치해 오프라인에서도 사용 가능
- 모바일 우선 반응형 UI, 다크모드 지원 — 설정은 **학습 설정 / 일반** 두 탭으로 나뉘어 있어요

## 브랜드

이름의 **O**는 선(禪)의 원(엔소)이고, 가운데 점은 의식의 시작입니다. 원은 일부러 닫지 않아요 — 열린 자리가 아직
되어가는 중인 부분이니까요.

| | Background | Surface | Text | Accent | Highlight |
|---|---|---|---|---|---|
| 기본 (순수함·균형·가능성) | `#F7F5F0` | `#FFFFFF` | `#1A1A1A` | `#8A9A5B` | `#C9A227` |
| 다크 (깊이·내면·본질) | `#111111` | `#1B1B1B` | `#F5F5F0` | `#A8C686` | `#D8B44A` |

- **여백/시작** 모든 가능성의 공간 · **본질/존재** 선명함과 집중 · **조화/생명** 자연과 성장 · **깨달음/빛** 가치와 통찰
- 팔레트는 `src/index.css`의 `@theme`에 한 번만 정의됩니다. 색을 바꾸려면 그 블록만 고치면 돼요.
- 금색(Highlight)은 아껴 씁니다 — 연속 학습일, 목표 달성처럼 "깨달음"에 해당하는 순간에만.
- 마크는 `scripts/gen-enso.mjs`가 생성합니다. 좌표를 직접 고치지 말고 상단 상수를 조정한 뒤 다시 실행하세요.

## 기술 스택

- React 19 + TypeScript + Vite
- Tailwind CSS v4
- 데이터 저장: `localStorage` (브라우저 로컬 저장, 서버 없이 동작)
- 발음: Web Speech API (`speechSynthesis`)
- 사전/번역: [Free Dictionary API](https://dictionaryapi.dev)(영어 발음·정의) + [MyMemory](https://mymemory.translated.net)(번역, 무료·키 불필요) — 두 API 모두 실패 시 수동 입력으로 자연스럽게 대체됨
- 파일 가져오기: `read-excel-file`(xlsx/csv), `mammoth`(docx)
- PWA: `vite-plugin-pwa`(Workbox) — 앱 셸을 프리캐시해서 오프라인 동작

새 설치는 예시 단어 없이 **빈 단어장**으로 시작합니다.

> **백업을 권합니다.** 데이터는 이 브라우저의 localStorage에만 있습니다. 브라우저 데이터를 지우거나 기기를 바꾸면 사라지고,
> Safari는 일정 기간 방문이 없으면 저장소를 자동 삭제합니다. 설정 → 데이터 백업에서 가끔 파일로 내보내 두세요.

## 개발

```bash
npm install
npm run dev            # 개발 서버 (http://localhost:5173)
npm run build          # 프로덕션 빌드
npm run preview:pages  # 빌드 결과를 GitHub Pages와 동일하게 /-/ 하위 경로로 서빙
npm run lint           # oxlint 검사
npm run check:srs       # 간격 반복 알고리즘 + 데이터 마이그레이션 검증
npm run check:halflife  # 난이도 반감기 모형 시뮬레이션 (참값을 알고 있는 데이터로 회수율 측정)
```

### 반감기 모형에 대해 알아둘 것

`npm run check:halflife`는 참값을 아는 가상 데이터를 앱의 실제 스케줄러로 돌려 모형이 그걸 얼마나 회수하는지 잽니다.
시뮬레이션에서 확인된 것:

- **어려움 확정은 믿을 만합니다.** 모든 시나리오·모든 확신도 구간에서 오분류 0%.
- **쉬움 확정은 거의 나오지 않습니다.** 구조적 한계예요 — 쉬운 단어일수록 복습 간격이 길어져 관측이 적고,
  간격이 반감기보다 훨씬 짧으면 "아직 안 잊었다"에서 얻을 정보가 거의 없습니다. 일부러 늦게 물어보는 탐침도
  넣어봤지만(5~10%를 2.5~4배 간격으로) 개선이 없어서 채택하지 않았습니다.
- **예상 기억률은 확실히 좋아집니다.** 평균 절대 오차가 기존 SM-2 간격 방식 0.160 → 0.083으로 절반입니다.
- 그래서 모형은 기억률 예측과 어려움 확정에 쓰고, 나머지는 오답률 잠정 판정이 받칩니다.

> `vite preview`는 base가 루트가 아닐 때 진입 스크립트 요청(`Sec-Fetch-Dest: script`)에 404를 반환합니다.
> 빌드 결과 확인은 `npm run preview:pages`를 쓰세요.

## 배포

`claude/new-session-og2xyu` 브랜치에 push하면 GitHub Actions가 자동으로 빌드해서 GitHub Pages에 배포합니다.

- 주소: `https://aswqpp.github.io/-/`
- 저장소 이름이 `-`이라 앱이 `/-/` 하위 경로에 놓입니다. `vite.config.ts`의 `PROD_BASE`와 PWA `scope`/`start_url`이 여기에 맞춰져 있습니다.
- **최초 1회만** 저장소 Settings → Pages → Source를 **GitHub Actions**로 지정해야 합니다.
